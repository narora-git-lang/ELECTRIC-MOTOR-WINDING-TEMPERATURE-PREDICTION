# Electric Motor Winding Temperature Prediction

## Overview
A supervised machine learning regression project that predicts
electric motor winding temperature using sensor measurements.

## Objectives
- Analyze electric motor sensor data.
- Apply machine learning regression techniques.
- Predict winding temperature from input features.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Models
- Linear Regression
- Random Forest Regression

## Project Structure
- `ElectricMotorTemperaturePrediction.ipynb` - Project notebook
- `README.md` - Project documentation

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Download the dataset and place it in the appropriate directory.
